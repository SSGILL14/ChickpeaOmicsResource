# Add or update a resource

Edit [README.md](README.md) and open a pull request. Copy this complete card under the appropriate heading:

```html
<table width="75%">
<tr><td width="690" valign="top">
<h3><a href="https://github.com/OWNER/REPOSITORY">Resource name ↗</a></h3>
<p>One short description of the resource.</p>
</td></tr>
</table>
```

Use one card per row. The fixed cell width keeps cards compact on desktop; GitHub controls the final rendering.

- Include chickpea resources, or related tools with a clear use in chickpea research.
- Prefer the original authors' repository or portal.
- Use one factual sentence, ideally under 12 words. Mention broader species coverage when needed.
- Check links and note access restrictions or archived status when relevant.
- Avoid duplicates; keep entries alphabetically within each section.

Alternatively, [suggest a resource](https://github.com/SSGILL14/ChickpeaOmicsResource/issues/new?template=suggest-resource.md).

## Maintainers

Check relevance, links and duplicates. Add accepted suggestions to README.md and close the issue. Review links periodically. README.md is the only resource list to maintain.
